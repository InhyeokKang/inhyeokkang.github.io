주요 연구·과제

초저전력 IoT 기반 웨어러블 시스템 과제

연구책임자

2024.07 – 2025.06 · 교육부 · 요구분석·모델링·개발·디버깅

장치별 데이터 전송량을 고려한 통신 자원 배분과 거리·전력 예측 소프트웨어를 개발했습니다.

  • 문제: 데이터가 많이 모이는 장치의 전송 지연과 거리 추정 오차를 줄여야 했습니다.
  • 해결: 장치별 전송 부담에 따라 전송 순서와 간격을 조정했습니다. CSI(Channel State Information, 채널 상태 정보)를 전처리하고, 거리·전력 예측 모델을 구현해 단계별 입출력과 성능을 검증했습니다.
  • 결과: 기존 통신 방식 대비 평균 처리량 44.32% 향상·지연 최대 63.94% 감소를 확인했습니다. 거리 예측 오차는 기존 신호세기 기반 방식 대비 약 60.3% 줄였습니다(RMSE 1.171 → 0.465).

통신 성능은 시뮬레이션 비교 결과입니다. 공식 과제명: On-Device 머신러닝 기반 에너지 자립형 웨어러블 헬스케어 시스템 연구.

차량 이더넷 통신 성능 개선

공동 연구

OMNeT++/INET · Ethernet/TSN · 알고리즘 설계·시뮬레이션 구현·실험 데이터 정리 참여

  • 문제: 긴급 데이터가 몰리면 기존 전송 일정이 밀리면서 제어·영상 데이터의 지연도 커졌습니다.
  • 해결: 긴급 데이터의 전송 시간을 계산해 스위치의 전송 일정을 조정하고, 남는 시간을 다른 데이터 전송에 활용하도록 구현·평가했습니다.
  • 결과: 기존 방식(eTAS) 대비 평균 처리량 32.04% 향상·평균 통신 지연 8.91% 감소를 시뮬레이션에서 확인했습니다.

실습 자료 제작·지도

2023년 2학기 – 현재 · 학부 실습조교

운영체제·임베디드시스템·IoT네트워크 과목의 실습 자료와 예제 코드를 직접 제작하고, 환경 설정부터 구현·동작 확인까지 실습을 지도했습니다.

운영체제

Linux의 파일 입출력, 프로세스, 통신 동작을 이해하도록 C 예제를 제작했습니다. GCC·Make 빌드, fork/exec, 프로세스 간 통신, 소켓 송수신 결과를 함께 확인했습니다.

임베디드시스템

Raspberry Pi에서 센서 입력을 읽고 주변장치를 제어하는 실습을 구성했습니다. 원격 접속·환경 설정, 버튼·센서 입력에 따른 LED 제어, LCD 온습도 표시 등을 다뤘습니다.

IoT네트워크

장치 데이터를 서비스로 연결하는 과정을 실습하도록 MQTT 메시지 송수신, DB 저장, GUI·웹 화면 표시 예제를 제작하고 설정·코드·결과를 자료로 정리했습니다.

담당 실습에서 중도 낙오 없이 모든 학생이 실습을 완료했고, 전원 실습 평가에서 만점을 받았습니다.
